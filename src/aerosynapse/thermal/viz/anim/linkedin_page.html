3  How to post

  1. Start a post on LinkedIn and paste the full or the short text.
  2. Attach one media type: the video (teaser.mp4), or the PDF as a document (give it a title, e.g. “{title}”), or up to 20 images from carousel/.
  3. Check the link and the hashtags; add your name to the cards by setting author in the config if you want it shown.
  4. Post it yourself. Nothing here is uploaded or posted automatically.
