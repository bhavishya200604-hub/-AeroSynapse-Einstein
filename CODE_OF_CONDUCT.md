# Code of Conduct

This project follows the spirit of the Contributor Covenant, version 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful,
assume good faith, criticise ideas and evidence rather than people, and keep scientific
disagreement grounded in reproducible results. Report unacceptable behaviour to the maintainer
through the contact on the GitHub profile of the repository owner.
